# Шерпа для Telegram

Генерация: `python tools/telegram_export.py` (из корня проекта; нужен ffmpeg с libvpx-vp9 — в PATH или через `imageio_ffmpeg`).
Позы: idle, walk, wave, think, jump, sleep, look. Кадры те же, что в GIF питомца (4 кадра по 0,22 с).

## Что где лежит
- `stickers/sherpa_<поза>.webm` — видеостикеры 512×512 (пёс ×17 без сглаживания, по низу холста).
- `emoji/sherpa_<поза>.webm` — custom emoji 100×100 (пёс ×3).
- `stickers_static/sherpa_<поза>.png` — статичные стикеры 512×512 (первый кадр позы).
- `icon_100.png` — значок набора 100×100.

## Требования Telegram (по https://core.telegram.org/stickers)
- Видеостикер: WebM, VP9, без звука, одна сторона ровно 512 px (другая ≤512), ≤3 с, ≤30 к/с, ≤256 КБ, зацикленный.
- Видео-эмодзи: то же, но 100×100.
- Статичный стикер: PNG/WebP, одна сторона 512 px.

Сверено с официальной страницей 20.11.2026: всё выше. Не сверено (на странице этого нет, написано по памяти):
предел размера статичного стикера, значок набора (WebM 100×100 до 32 КБ), число стикеров в наборе
и команды бота ниже — уточняйте у самого @Stickers.

## Загрузка через @Stickers
1. Видеостикеры: `/newvideo` → название набора → отправляйте `.webm` файлом (как документ), к каждому — эмодзи; `/publish`, затем короткая ссылка.
2. Эмодзи: `/newemojipack` → выберите тип «видео» → название → отправляйте файлы из `emoji/`; `/publish`.
3. Статичные: `/newpack` → название → отправляйте PNG из `stickers_static/` с эмодзи; `/publish`.
В наборе до 120 стикеров (эмодзи — до 200). Значок: `/seticon` (для статичного набора можно `icon_100.png`).
